3. 수집 단계별 흐름

  1. step00_erd_schema: ERD/schema artifact 생성 또는 갱신.
  2. step01_main_list: main listing 수집 및 listing 필드 저장.
  3. step02_main_targets: main 후보 dedupe, 최초 등장 기준 main_rank 부여.
  4. step03_bsr_list: BSR listing 수집.
  5. step04_bsr_rank: BSR 후보 dedupe, bsr_rank 1~100 생성.
  6. step07_final_targets: main/bsr merge. 중복 SKU/URL은 기존 rank를 덮어쓰지 않음.
  7. step08_detail_enrichment: PDP/detail/spec/shipping/similar/rating 보강.
  8. step09_review20: 상세 리뷰 본문 최대 20개 보강.
  9. step15_final_output: DB용 최종 컬럼 순서와 format 변환.
  10. step16_field_audit: 필드 blank/형식/의심값 audit.
  11. step11_s3_sync: full run 기준 S3 sync.
  12. step13_db_prepare: 제품군별 DB table 생성.
  13. step14_db_load: final_output.csv DB insert.
  14. step10_status_check: 상태 점검.
  15. step12_local_cleanup: cleanup.

4. 제품군별 고유 수집 컬럼

제품군고유 컬럼수집 위치 / exact key
TVsku, screen_size, estimated_annual_electricity_use, model_yearGraphQL item/factsheet. SKU는 Modelo, screen은 Polegadas 또는 Tamanho da tela, energy는 Consumo aproximado de energia/Consumo de energia/Consumo mensal de energia/Consumo energetico, year는 Ano de lancamento.
REFref_refrigerator_type, ref_capacity, sku_short_version, skufactsheet. type은 Porta, capacity는 Capacidade Liquida Total 또는 Capacidade Total, SKU는 Referencia/Modelo.
LDYldy_loading_type, ldy_color, ldy_capacity, sku_short_version, skufactsheet. loading은 Tipo de Abertura/Tipo de Abertura Eletrodomestico/Tipo de Abertura Electrodomestico, capacity는 Capacidade de Lavagem, SKU는 Referencia/Modelo.

5. 수집방식

  • Listing: Magalu federation GraphQL searchQuery direct first. direct 결과 수가 부족하거나 blocked면 browser GraphQL/session fallback.
  • Detail/spec: federation GraphQL itemQuery. 필요 시 browser GraphQL/PDP HTML fallback.
  • Shipping: item offer/seller/dimensions 기반 shipping request. ZIP 01001-001 기준.
  • Review: GraphQL ProductRating. commentCount 기준 최대 min(20, commentCount)개 리뷰 본문 수집.
  • ZenRows: 기본 수단이 아니라 fallback/probe 용도. 대량 사용 전 비용 판단 필요.

7. 실행 및 브라우저 안정화

실행 BAT

파일용도순서/특징

run_magalu_casas_interleaved_tv_ref_ldy_full.batMagalu/Casas Bahia 교차 full runMagalu TV → Casas TV → Magalu REF → Casas REF → Magalu LDY → Casas LDY. 기본 대기시간은 0초.

Chrome/OOM 대응

  • Magalu browser session은 SEDA_MAGALU_BROWSER_MAX_USES=50 또는 SEDA_MAGALU_BROWSER_MAX_AGE_SECONDS=1200 기준으로 recycle한다.
  • Chrome OOM/error page marker(chrome-error://, chromewebdata, out of memory, Aw, Snap 등)를 감지하면 session을 닫고 재시작한다.
  • SEDA_MAGALU_BROWSER_CLOSE_ON_EXIT=1이면 step subprocess 종료 시 crawler Chrome session을 닫는다.
  • 교차 BAT는 Magalu와 Casas를 제품군 단위로 번갈아 실행해 한 retailer에 연속 부하가 몰리는 것을 줄인다.

운영 메모

  • 환경값은 repo root .env 또는 seda/.env에서 로드한다. .env는 git 관리 대상이 아니다.
  • 기본 ZIP/postal code는 01001-001.
  • exact key 정책: spec/factsheet는 부분 문자열 매칭으로 확대하지 않는다. exact key를 모르면 추가 전에 확인한다.
  • exact key value 정책: exact key에서 나온 값은 원문 그대로 저장한다. 180, 20226 같은 값도 exact key에 있으면 blank 처리하지 않는다.
  • 실행 BAT: run_magalu_tv_ref_ldy_full.bat.
